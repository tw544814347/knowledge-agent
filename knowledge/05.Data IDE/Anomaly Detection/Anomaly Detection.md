# Anomaly Detection

> **Page ID**: 2366350088
> **URL**: https://confluence.shopee.io/pages/viewpage.action?pageId=2366350088

## 背景

现有业务均有告警方面的诉求（NOC），用以发现业务/系统问题，公司的监控平台能够提供常规的基于阈值的告警配置。但是由于业务本身的动态性，很多场景下用户在公司监控平台上无法很好的完成有效监控的配置。常见的一些比较难配置告警的场景如下：

1. 大促时的流量急剧上涨，以及大促过会流量急剧下跌。绝对数值值阈值配置会产生较多误告，前一天环比类告警也会产生较多告警；
2. 小流量情况下，数值稍微拨动，比例类告警配置会产生较多误告；
3. 业务流量的突刺（向上/向下），以及压测/放量对告警配置的影响；
4. 告警阈值通常会设置得过严格/过宽松，会导致出现较多告警或者漏告警；
5. 随着时间的变化，业务指标特性会动态变化，基于传统阈值的告警需要较多的人工维护成本；

## 目标

基于业务现有上报监控平台的数据，提供基于模型的动态异常检测的服务，主要目标优化周期性数据的业务告警准确性，降低告警配置及维护成本。

同时和监控平台打通，提供可视化的数据预测服务，降低用户使用成本。
