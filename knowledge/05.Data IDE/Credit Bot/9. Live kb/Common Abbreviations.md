# Common Abbreviations

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=3158462820

业务与数据侧 **常用英文缩写** 及 **中文释义**，便于文档、SQL 与 Credit Bot 对话统一理解。

---

## Comprehensive Table（业务缩写综合表）

| 缩写 | 英文全称 / 概念 | 中文说明 |
|------|-----------------|----------|
| **SPL** | Seller/Shop Pay Later（语境相关） | 卖家侧先买后付 / 分期支付类产品 |
| **BCL** | Buyer Cashloan | 买家现金贷 |
| **SCL** | Seller Cashloan | 卖家现金贷 |
| **CL** | Cashloan | 现金贷总称或域统称 |
| **BNPL** | Buy Now Pay Later | 先买后付 |
| **CF** | Consumer Finance | 消费金融相关业务或通道 |
| **FES** | （内部产品域）发票融资/供应链金融 | 对公融资与发票类业务 |
| **LDN** | Loan Document Number（或内部借据号体系） | 借据编号类标识 |
| **DPD** | Days Past Due | 逾期天数 |
| **EIR** | Effective Interest Rate | 实际年化利率 |
| **NIR** | Nominal Interest Rate | 名义利率 |
| **MOB** | Month on Book | 在账月份/账龄 |
| **PAR** | Portfolio at Risk | 风险敞口（定义依报表） |
| **WO** | Write-off | 核销 |
| **KYC** | Know Your Customer | 客户身份识别与尽职调查 |
| **AML** | Anti-Money Laundering | 反洗钱 |
| **ABS** | Asset-Backed Securities | 资产证券化 |
| **JFS** | （内部）金服/资金相关主体或通道 | 依上下文指资金方或平台 |
| **Channeling** | Bank channeling / 联合贷导流 | 与银行合作放款或导流模式 |
| **ODS** | Operational Data Store | 贴源数据层 |
| **DWD** | Data Warehouse Detail | 明细数据层 |
| **DWM** | Data Warehouse Middle | 中间层 |
| **DWS** | Data Warehouse Summary | 汇总数据层 |
| **ADS** | Application Data Service | 应用数据层 |
| **DIM** | Dimension | 维度表 |
| **PTP** | Promise to pay | 承诺还款 |
| **RPC** | Right party contact | 有效联系人接通 |
| **IVR** | Interactive Voice Response | 交互式语音应答 |
| **AHT** | Average handle time | 平均通话处理时长 |
| **ACW** | After call work | 话后整理 |
| **UC** | User Center（常见库名） | 用户中心相关宽表域 |
| **SKU / SPU** | Stock keeping / Product unit | 商品最小库存/产品单元（电商） |
| **ROI / ROA** | Return on investment / assets | 投资回报/资产回报 |

---

## Usage Notes（使用说明）

- 同一缩写可能在 **不同国家产品** 下含义略不同，以 **Confluence 产品页 + 数据字典** 为准。
- 写 SQL 时 **字段名优先英文**，注释可用中英文对照关键缩写。
- 新增缩写建议在 **本表补充** 并带上 **pageId** 或内部链接便于溯源。
