## 1. 背景与目标

DataJoi 是基于 RAG（Retrieval-Augmented Generation）架构的知识问答系统，服务于 FP 数据仓库的元数据查询场景。随着系统能力不断拓展（Mart Datameta、ODS Datameta、说明文档、FAQ 等多知识源），需要建立一套**系统化、可量化、可持续迭代**的评测体系，以：

* **量化系统质量**：对检索、生成、端到端各环节的表现进行客观度量
* **驱动质量提升**：通过定期评测发现瓶颈环节，指导针对性优化
* **保障变更安全**：在知识库更新、模型升级、Pipeline 改动时，通过回归评测避免质量退化
* **支撑架构决策**：以数据为依据，支持模型选型、检索策略调优等技术决策

## 3. 评估指标体系

### 3.1 检索质量指标

#### 3.1.1 Contextual Relevancy（上下文相关性）

| 属性 | 说明 |
| --- | --- |
| **类型** | 检索质量 |
| **定义** | 检索到的上下文内容与用户问题的相关程度。低相关性会导致生成答案时引入无关信息。 |
| **所需输入** | `input`（用户问题）、`retrieval_context`（检索上下文） |
| **是否需要标准答案** | 否（Referenceless） |

**计算方法**：
1. 使用 LLM 从 `retrieval_context` 中提取所有陈述（statements）
2. 使用同一 LLM 判断每条陈述是否与用户 `input` 相关
3. 计算得分: 相关陈述数 / 总陈述数

> **解读**：分数越高，说明检索系统返回的内容越有针对性，无关"噪音"越少。

#### 3.1.2 Contextual Recall（上下文召回率）

| 属性 | 说明 |
| --- | --- |
| **类型** | 检索质量 |
| **定义** | 检索到的上下文中包含正确答案所需关键信息的比例。 |
| **所需输入** | `expected_output`（标准答案）、`retrieval_context` |
| **是否需要标准答案** | 是（Reference-based） |

#### 3.1.3 Contextual Precision（上下文精确率）

| 属性 | 说明 |
| --- | --- |
| **类型** | 检索质量 |
| **定义** | 评估 RAG 检索器中 re-ranker 的排序质量 |
| **所需输入** | `input`、`expected_output`、`retrieval_context` |
| **是否需要标准答案** | 是（Reference-based） |

### 3.2 生成质量指标

#### 3.2.1 Faithfulness（忠实性）

| 属性 | 说明 |
| --- | --- |
| **类型** | 生成质量 |
| **定义** | 生成答案中的事实是否完全基于所提供的上下文，没有产生幻觉。 |
| **所需输入** | `actual_output`、`retrieval_context` |
| **是否需要标准答案** | 否（Referenceless） |

#### 3.2.2 Answer Relevancy（答案相关性）

| 属性 | 说明 |
| --- | --- |
| **类型** | 生成质量 |
| **定义** | 生成的答案是否紧扣用户问题，不包含冗余或不相关的内容。 |
| **所需输入** | `input`、`actual_output` |
| **是否需要标准答案** | 否（Referenceless） |

### 3.3 端到端综合指标

#### 3.3.1 Answer Correctness（答案正确性）

答案正确性由**事实相似度**和**语义相似度**两部分加权组合而成。

### 3.4 多轮对话指标（Future）

基于滑动窗口（Sliding Window）机制在对话历史上逐轮计算。

### 3.5 指标全景总结

| 指标 | 类型 | 需标准答案 | 评估对象 | 公式核心 |
| --- | --- | --- | --- | --- |
| Contextual Relevancy | 检索质量 | 否 | 检索器 | 相关陈述 / 总陈述 |
| Contextual Recall | 检索质量 | 是 | 检索器 | 可归因陈述 / 总陈述 |
| Contextual Precision | 检索质量 | 是 | 检索器 | 加权累积精确率 |
| Faithfulness | 生成质量 | 否 | 生成器 | 忠实声明 / 总声明 |
| Answer Relevancy | 生成质量 | 否 | 生成器 | 相关陈述 / 总陈述 |
| Answer Correctness | 端到端 | 是 | 全链路 | F1 + 语义相似度加权 |

## 4. 评测框架选型

### 4.2 选型结论

**主选：DeepEval** + **辅助：Ragas**

| 框架 | 角色 | 理由 |
| --- | --- | --- |
| **DeepEval** | 主评测框架 | 指标丰富（60+）、原生 pytest 集成、CI/CD 友好 |
| **Ragas** | 辅助/参考 | RAG 核心质量评估指标学术背景扎实 |
