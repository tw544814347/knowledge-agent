# 不同角色RAG需求

> **Page ID**: 2769236369
> **URL**: https://confluence.shopee.io/pages/viewpage.action?pageId=2769236369

| 角色 | 常见使用场景 | 关注文档 | 查询风格 | 输出偏好 |
| --- | --- | --- | --- | --- |
| 产品经理 | - 查询功能需求  - 了解设计逻辑  - 理解保险条款 | - PRD（产品需求文档）  - 设计文档  - 产品文档（条款） | 目标导向、自然语言、不强调技术细节 | 简明摘要分点说明高亮重点 |
| 后端开发 | - 查接口协议  - 查表结构字段含义  - 理解微服务逻辑 | - 技术方案文档  - API定义  - 数据表定义  - 架构设计 | 精准关键词驱动接口名、字段名、服务名 | 原始文档片段代码块或结构化表格有引用路径 |
| 前端开发 | - 查询组件使用方式  - 理解交互逻辑  - 查后端接口字段说明 | - Figma注释/命名  - PRD  - Swagger/API 文档 | 图文结合式需求问题常围绕 UI 组件名 | 精炼组件说明链接到 Figma接口字段列表 |
| 测试/QA | - 查测试点  - 查业务流程  - 查历史缺陷  - 理解接口行为 | - 测试报告  - 事故报告  - 数据口径说明 | 常使用“怎么测”、“有没有覆盖”类问题 | 明确步骤可枚举列表对应文档段落 |
| 数据/算法工程师 | - 查字段口径  - 理解数据来源  - 查模型部署方式 | - 数据 Mart 文档  - 数据表说明  - 模型设计方案 | 精准表/字段/指标名或模糊业务术语查询 | 结构化字段说明来源+逻辑关系链引用来源 |
| SRE / 运维 | - 查故障处理流程  - 查服务依赖链  - 查部署/上线文档 | - 事故报告  - 技术运维方案  - 架构图文 | 故障关键词驱动时间/服务维度常用 | 步骤式流程输出关联服务图谱或链路说明 |
