# .cursor 目录

此目录包含 Cursor 编辑器相关的配置和工具文件。

## 文件结构

```
.cursor/
├── ask.py                 # Ask 工具：AI与用户交互式沟通工具
├── changelog.md           # 项目变更记录
├── project_plan.md        # 项目计划和任务清单
└── README.md             # 本说明文档
```

## 文件说明

### ask.py
AI与用户之间的交互式沟通工具，用于：
- 任务验收和确认
- 需求澄清和选择
- 支持Markdown渲染
- 多选项交互界面

使用方式：
```bash
ask '<问题内容>' "<选项1>" "<选项2>" ...
```

### changelog.md
记录项目的所有重要变更，包括：
- 功能新增
- 架构调整
- Bug修复
- 性能优化

### project_plan.md
项目的计划和进度跟踪，包含：
- 任务清单
- 进度状态
- 里程碑规划

## 使用说明

这些文件主要用于：
1. **项目管理**：跟踪开发进度和变更
2. **团队协作**：提供统一的沟通工具
3. **文档记录**：保持项目历史和决策记录

## 注意事项

- ask.py 需要 uv 和 rich 依赖支持 Markdown 渲染
- changelog.md 应在每次重要变更后及时更新
- project_plan.md 反映当前的开发状态和计划
