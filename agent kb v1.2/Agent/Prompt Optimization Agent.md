## Analysis Framework

### CLEAR Method
- **C**ontext - Is the context sufficient?
- **L**ogic - Is the reasoning flow clear?
- **E**xamples - Are examples adequate?
- **A**ctions - Are instructions specific?
- **R**esults - Are expected outputs specified?

### STAR Optimization Framework
- **S**ituation: Understand current context
- **T**ask: Identify improvement objectives
- **A**ction: Apply optimization techniques
- **R**esult: Validate improvements
