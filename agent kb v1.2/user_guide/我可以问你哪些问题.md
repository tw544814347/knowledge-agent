## 三、推荐的三种提问姿势

### ① 直接查事实型（短问 → 短答）
> "SPL 业务里 mart 表的命名模式是什么？"
> "Compass embedding 的申请文档在哪？"

### ② 对比分析型（给出 A 和 B，让我对比）
> "Milvus 和 Qdrant 在本地部署 RAG 时各自的优劣？"
> "LangChain 和 LlamaIndex 做 RAG 的定位差异？"

### ③ 总结整理型（让我帮你聚合多篇）
> "帮我梳理一下 Credit Bot 最近几次会议的关键决策。"
> "把 RAG 评估相关的几篇文档整理成一份 checklist。"

### ④ 结合联网搜索（点 🌐 后再提问）
> "对比我知识库里的 RAG 调研方案，业界最新的 RAG 架构有哪些新进展？"
> "我们用的 Milvus，最近一年有哪些重要更新？"

## 四、我**不**擅长 / 可能答不好的问题

| 类型 | 例子 | 为什么 |
|---|---|---|
| 需要实时数据 | "今天的股价 / 天气 / 汇率" | 知识库是静态的，需开启联网 |
| 纯主观判断 | "你觉得哪家公司更好？" | 我只根据文档说话，不给个人意见 |
| 知识库外的专业领域 | 法律条款精确解释、医学诊断 | 不在覆盖范围，建议咨询专业人士 |
| 极度碎片化的元问题 | "你第 3 页第 5 行写了什么？" | 我按语义检索，不按页码定位 |
| 超长跨文档深度推理 | "把所有 50 篇文档的所有观点都串起来证明一个命题" | 上下文窗口有限，建议分步问 |

遇到这些情况，我会**如实告诉你"未找到相关内容"**，而不是编造答案。

## 五、小技巧

- 🔖 **点赞好答案**：每条回答下方有 👍，点赞后会自动归档到你的"精选"，方便日后复盘。
- 📄 **点击来源可预览**：引用的知识库文档会在右侧弹出可滚动预览窗口。
- 🌐 **联网外链可跳转**：联网来源会在新标签页打开原网页。
- 💬 **单次对话 50 轮上限**：超过会自动丢弃最旧的问答对，建议重要对话尽早点赞保存。
- 🔄 **新开话题用"新对话"**：不同主题分开聊，上下文更干净、回答更准。
- 📱 **手机端友好**：侧边栏会以抽屉形式打开，不挤压聊天区。
