## step4、http模型服务的调用

https://aimos.fp-data.test.shopee.io/shark/anomaly/detect

Post Header参数Authorization：  
**key：** Authorization  
**value(Bearer)：** Bearer (token)

**参数含义:**

必选：time\_series 时间序列  
可选：algo\_type 可以指定算法名称  
可选：custom\_type  
可选：rule\_config  
只传入time\_series 会自动路由算法

**返回结果：**
```json
{
  "code": 0,
  "data": "{\"anomalies_result\":{\"anomalies\":[],\"anomaly_scores\":[],\"time_series\":[],\"yhat_upper\":[],\"yhat_lower\":[]}}",
  "message": "success",
  "requestId": "1e53e00d978240a8b14de8cc0646ee4b"
}
```

**结果含义：**  
anomalies\_result 是否异常  
anomaly\_scores 异常得分  
yhat\_lower 预测下界限  
yhat\_upper 预测上界限  

注意：只有包含预测能力算法才会有yhat\_lower,yhat\_upper

## 多维度

目前支持 ocsvm, rrcf 两个模型

调用参数
```json
{
  "time_series": [[1,2,3,1,...],[1,2,3,1,...]],
  "algo_type": {"algos": ["rrcf"]},
  "rule_config": {"algorithmType": "up", "sensitivity": "mid"}
}
```

## 5、时序异常子类型检测接口

https://aimos.fp-data.test.shopee.io/shark/anomaly/classifier

请求参数
```json
{
  "time_series": [10, 8, 13, 14, 15, 16, 17, 18, 19, 20, 16, 22, 19, 17, 28, 18, 22, 29, 33],
  "detect_type": ["steep_drop", "up_down", "drop_zero", "sim", "trend_anomaly"],
  "len": 5
}
```

返回结果
```json
{
  "code": 0,
  "data": "{\"code\":200,\"classifier\":{\"drop_zero\":[0,0,0,1,1],\"up_down\":[0,0,0,1,1],\"sim\":[0,0,0,0,0],\"variation\":[0,0,0,0,0]},\"message\":\"success\"}",
  "message": "success",
  "requestId": "e52d39c527dc47e4bed9a51e70f48159"
}
```

子类型含义：steep\_drop(陡降)、up\_down(冲高回落)、drop\_zero(掉0)、sim(周期相似性)、trend\_anomaly(趋势变化)
