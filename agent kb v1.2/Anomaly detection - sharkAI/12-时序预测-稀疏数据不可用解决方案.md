# 时序预测-稀疏数据不可用解决方案

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2923634517

## 背景

稀疏时间序列常见于 API QPS、日志量等监控场景，零值与极端值齐发。SparseGaussianTailDetector通过 **高斯尾概率检测 + 稀疏度校验** 双重机制，精准识别"密度 × 均值"联合变化的异常区段

## 数据流 & 处理流程

```
原始序列 raw_series
  → 去极值 + 插值
  → 滑动窗口循环
    → 长期窗口统计 (μ_long, σ_long, p_long)
    → 短期窗口统计 (μ_short, σ_short, p_short)
    → Z-score 计算
    → 尾概率 p
    → p < 阈值? → 标记短窗区段
  → 可选: 密度检验 → p_density < 阈值? → 标记短窗区段
  → labels → events
```
