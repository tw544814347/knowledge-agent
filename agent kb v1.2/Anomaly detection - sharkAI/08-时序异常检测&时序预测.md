# 时序异常检测&时序预测

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2557024787

一、平台介绍
------

### 智能算法

* 集成BiLSTM、Dlinear和Transformer等深度算法模型，ESD、MAD、3sigma等统计模型和Xgboost等机器学习模型联合决策来实现指标预测和动态阈值生成
* 随机波动型、稳定型和周期型指标有效报警实现业务免配置的简单、高效、精准的智能监控服务
* 基于自动识别算法智能优化，并针对不同指标类型训练调优对应的指标预测、异常检测模型
* **一套异常检测算法支持所有时序指标的预测和异常检测**，理论上只要是有规律的时序数据，都可以进行预测和异常检测。

### 开箱即用

- 无需配置复杂的告警规则，一键开启智能预测  
- 自动生成动态上下限阈值  
- 开箱即用，操作简单、灵活易用
