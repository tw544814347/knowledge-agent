# Shark-AI 异常检测平台-业务接入SOP

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2905188099

**面向业务与数据同学，提供分钟级时间序列的快速接入指南、能力边界、评估口径与自查清单**

## 1. 适用范围与目标

* **支持指标类型**：QPS流量/吞吐，成功率，错误率，资源使用（CPU/Mem）。
* **适用数据形态**：有规律的时序数据，比如周期性，平稳性，趋势性的分钟级时间序列。
* **目标**：以较低误报、零漏报目标，提供可解释的分级告警能力。

![image2025-9-25_15-12-58.png](https://confluence.shopee.io/download/attachments/2905188099/image2025-9-25_15-12-58.png)

## 2. 接入前准备（平台接入监测内容）

* **粒度**：分钟级（minute-level）
* **数据量**：连续 ≥ 3 天数据（建议 ≥ 7 天以提升稳健性）
* **缺失占比**：< 20%（≥ 20% 视为不可用或高风险）
* **时间戳**：严格单调递增，无乱序/重复；无显著延迟/滞后
* **值域/量纲**：稳定且明确
* **异常历史**：若有重要历史异常/业务日历，建议补充

## 3. 指标类型与关注方向配置

* direction = down（关注下降异常）
* direction = up（关注上升异常）
* direction = both（双向关注）
* direction = trending（趋势异常）

![image2025-9-11_14-55-53.png](https://confluence.shopee.io/download/attachments/2905188099/image2025-9-11_14-55-53.png)

## 4. 检测策略选择

![image2025-9-11_14-53-56.png](https://confluence.shopee.io/download/attachments/2905188099/image2025-9-11_14-53-56.png)

* **仅阈值**：适合有稳定阈值、边界清晰的指标
* **复合阈值**：阈值 + 连续规则检测
* **复合检测组**：
  + 常规：陡降，陡升，掉0，历史相似匹配
  + 场景：冲高回落，趋势异常，大促，毛刺抑制

## 5. API 快速开始

端点：`POST /anomaly/detect`

请求示例：
```json
{
  "time_series": [1.0, 0.99, 0.98, 0.6, 0.99, 1.0],
  "algo_type": {},
  "rule_config": {},
  "custom_type": {}
}
```

响应示例：
```json
{
  "code": 200,
  "message": "success",
  "anomalies_result": {
    "anomalies": [0, 0, 0, 1, 0, 0],
    "anomaly_scores": [0.12, 0.18, 0.22, 0.92, 0.24, 0.13],
    "yhat_lower": [0.95, 0.95, 0.95, 0.95, 0.95, 0.95],
    "yhat_upper": [1.05, 1.05, 1.05, 1.05, 1.05, 1.05]
  }
}
```

## 6. 结果解读与分级

* z 值(绝对值)：
  + >= 3（宽松）
  + >= 2（适中）
  + >= 1（严格）
  + < 1 过滤
* 历史对齐与周期性：系统会根据昨同/周同/季节性对异常分数进行降权

## 7. SLO 与评估口径

* 误报率 ≤ 10%
* 漏报率 = 0%
* 告警频次 ≤ 0.5 次/天
* 统计口径：以业务标注/人工判别为准；以"异常窗口"为评估单元

## 8. 暂不支持与临时替代建议

1. **时序无序或需要监督异常判别** → 阈值检测 + TimeBandStop + DurationThreshold
2. **节假日/财报日的日历自适应阈值** → 配置屏蔽时间段 + 提高持续时长阈
3. **数据缺失/延迟超标**（≥ 20%） → 建议完善采集/上报SLA后再接入

## 9. FAQ 与自查清单

* 数据长度不足 → 补齐至连续≥3天分钟数据
* 时间戳乱序/重复 → 清洗为单调递增
* 值域爆裂/单位变更 → 提供 metric_range 或归一化
* 方向配置错误 → 对照第3章修正
* 告警过多 → 切换common组合；增大持续时长阈；启用历史对齐
* 告警过少 → 检查阈值是否过宽；缩短检测窗口；核对方向配置

## 10. 接入总览流程

```
分钟级数据(>=3天) → 数据检查 → 指标方向配置 → 模型预测 → 策略选择
  → 常规监测(陡降/陡升/掉0/历史相似匹配)
  → 场景监测(冲高回落/趋势异常/大促/毛刺抑制)
  → 检测执行 → 评分分级(z-score)
```
