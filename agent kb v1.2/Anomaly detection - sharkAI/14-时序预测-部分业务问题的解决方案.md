> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2947442556

1. 业务每次需要手动的调整时序的窗口方便做告警配置
2. 告警的阈值，白天和晚上不一样，需要分别做配置

### 路由模型

输入时序，解析时序的类型：**周期，趋势，稀疏，稳定性**

根据时序的类型选择不同的路由：
- 稳定+周期性 → Holt-Winters
- 稳定+非周期 → SARIMA
- 其他 → Linear Regression

时序预测的瓶颈：如果要提高上限，建议不符合上面时序类型的走监督分类模型。

```
开始: 输入时序数据
  → 稀疏性检测?
    是 → SparseGaussianTail稀疏模型判断
    否 → 时序类型判别
      周期+平稳 → Holt-Winters
      平稳 → SARIMA
      其他 → Linear Regression
  → 训练与预测
  → 效果达标?
    是 → 输出预测/告警
    否 → 人工或后端切换模型
```

### 窗口划分接口流程

```
输入: 业务时间序列
  → 数据类型判断
  → 周期类型数据 / 计算 rolling σ_i (L=15)
  → 按 breakpoints 映射到 state_idx
  → σ_i > 1.5·σ̂ ? → state_idx + 1 / 保持原 state_idx
  → 相邻同 state 合并
  → 强制最小区段长度 min_len
  → 极端低负载兜底判断
  → 输出: 区段及推荐窗口
```
