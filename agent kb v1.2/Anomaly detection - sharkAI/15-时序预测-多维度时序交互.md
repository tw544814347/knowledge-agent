# 时序预测-多维度时序交互

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2976337733

## 背景

支持业务多维度场景的配置

## 功能

### 1.多维度接入模块

比如配置：
```
sum by (payScenes) (
  increase(live_ph_spl_custom_business_data_counter{
    business="AccountLinking",
    cid="ph",
    method="AccountLinkingPayment"
  }[10m])
)
```
