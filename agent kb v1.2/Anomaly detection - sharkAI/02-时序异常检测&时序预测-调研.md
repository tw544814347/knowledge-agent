一、时序基本概念：
---------

窗口 (Window)  
窗口表示在时间序列中选取的一段连续数据子集  
Wi={xi,xi+1,…,xi+w−1}  
步长表示窗口在时间序列上移动的距离，步长为s时  
Wi={xi⋅s,xi⋅s+1,…,xi⋅s+w−1}

三、时序异常的特点(特征)
-------------

![image2024-9-24_16-18-5.png](https://confluence.shopee.io/download/attachments/2468534216/image2024-9-24_16-18-5.png)

from *UNSUPERVISED MODEL SELECTION FOR TIME-SERIES ANOMALY DETECTION*  
尖峰异常:要引入一个尖峰，我们首先抽取m ∼ Bernoulli(p)，如果m = 1，我们注入一个受正态分布s ∼ N(0, σ2)控制幅度的尖峰。  
翻转异常:我们反转时间序列：ts\_a[i, start:end] = ts[i, start:end][::-1]  
速度提升异常: 我们使用插值来增加或减少时间序列的频率，其中频率变化的因子（12或2）是用户定义的参数。  
噪声异常:我们注入从正态分布N(0, σ2)中抽取的噪声，其中σ是用户定义的参数。  
截断异常:我们将时间序列设置为N(0, σ2)或N(1, σ2)，其中位置参数和σ的选择都由用户定义。  
平均异常:我们运行一个移动平均值，其中窗口的长度（len\_window）由用户确定  
尺度异常:我们通过用户定义的因子（factor）对时间序列进行缩放  
漫游异常:我们根据用户定义的基线（baseline）增加了随基线增加的线性趋势  
上下文异常:我们对时间序列子序列进行线性函数aY + b的卷积

四、异常判断的原理
---------

移动平均  
这些模型将观测值与预定义大小的滑动窗口中最近观测值的"移动"平均值进行比较。

![image2024-9-24_16-18-47.png](https://confluence.shopee.io/download/attachments/2468534216/image2024-9-24_16-18-47.png)

k最近邻(k-NN)  
这些基于距离的异常检测模型将一段观测窗口与训练数据中的k个最近邻窗口进行比较。

![image2024-9-24_16-18-58.png](https://confluence.shopee.io/download/attachments/2468534216/image2024-9-24_16-18-58.png)  

LSTM-VAE是一个基于重构的模型

![image2024-9-24_16-19-14.png](https://confluence.shopee.io/download/attachments/2468534216/image2024-9-24_16-19-14.png)  

τ是一个异常阈值，常见的异常判断：  
1.统计分布的阈值设定（均值和标准差法）  
2.异常得分的阈值设定（异常比例（如1%或5%），选择相应得分作为阈值）  
3.基于滑动窗口的阈值设定  
4.基于模型的不确定性估计

六、问题解答
------

1.不同频率的时序怎么预测 → 数据频率的归一化，反归一化  
2.不同场景的怎么应用不同的算法 → 自动路由+用户自定义  
3.怎么选择模型参数 → BayesianOptimization  
4.遇到的lstm 时间滞后问题 → 特征处理，vmd,imf,emd分解或加入attention  
5.深度学习需要的历史样本 → 分钟级别数据，一般1-7天数据  
6.模型部署后可以做增量更新嘛 → 深度模型可以，knn,mad,prophet是批次的
