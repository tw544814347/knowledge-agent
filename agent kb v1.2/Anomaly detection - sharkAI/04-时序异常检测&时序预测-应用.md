应用主要讲（异常检测，时序预测）的模型方面

### 1.1 异常检测

* 基于六种方法：1.预测(forecasting) 2.重构(reconstruction) 3.距离(distance) 4.编码(encoding) 5.分布(distribution) 6.树方法(tree methods)
* 实现的模型包括：isolationForest,Seasonalesd,Sarima, Holt Winters, Prophet, DBSCAN, LSTM-AE, Dlinear, Nlinear, TSMixer等
* 评价指标：异常检测使用AUC，预测使用MSE和MAE
* 在多个数据集上进行了测试，如AirPassengers, art\_daily\_jumpsup, nyc\_taxi, TravelTime\_387, speed\_6005等

![image2024-9-24_16-2-49.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-2-49.png)

![image2024-9-24_16-3-12.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-3-12.png)

有周期和规律的数据，大部分时候效果都很不错；复杂时序的情况下，深度模型拟合效果比较好。

实际应用中的挑战：
---------

1. 不同类型的业务数据难以用单一模型处理
2. 高性能、低延迟要求：数据需要在线训练，在线推理
3. 模型的参数自动调优（贝叶斯优化器）
4. 反馈机制，模型的自适应（在线联调）

![image2024-9-24_16-21-57.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-21-57.png)

解决思路：
-----

1. Ensemble方法（当前做法，但耗性能，时效性差）
2. 模型选择器（训练一个模型来自动选择最佳检测器）
3. 自适应模型（后续提升方向）

![image2024-9-24_16-22-15.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-22-15.png)

Ensemble集成模型后，发现有大量的误告警，主要是稀疏数据的问题；  
解决方案：  
1.数据的区间数据变异系数  
2.双滑动窗口的高斯尾概率(arxiv 1607.02480)

![image2024-9-24_16-23-21.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-23-21.png)

当前还存在的问题：  
1.多维度组合下的异常判定  
2.稀疏数据的误告警问题

### 1.2 时序预测

![image2024-9-24_16-23-53.png](https://confluence.shopee.io/download/attachments/2468533995/image2024-9-24_16-23-53.png)

模型组成：
-----

* 数据处理层：数值分布，缺失值填充等
* Embedding层：将处理后的数据转为特征或向量
* 编码器层：利用深度学习模型生成高维空间的向量表征
* 解码器层：将向量表征映射到预测结果
* 优化目标：指导模型训练的损失函数

Embedding层类型：
- 无Embedding层
- MLP Embedding
- Patch Embedding
- CNN/RNN Embedding
- 多粒度Embedding

解码器类型：
- 简单vs复杂、单步vs多步、数值vs概率

优化目标（损失函数）类型：
- 值域相关（如MSE, MAE）
- 值域无关（如SMAPE, RMLSE, MAPE）
- 考虑形状的
- 概率相关（如quantile）
