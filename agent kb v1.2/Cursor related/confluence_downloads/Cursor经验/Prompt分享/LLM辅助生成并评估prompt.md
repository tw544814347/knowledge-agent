# LLM辅助生成并评估prompt

**页面ID:** 2785040739  
**URL:** https://confluence.shopee.io/pages/viewpage.action?pageId=2785040739

让LLM辅助生成并评估prompt：

1. 告诉 LLM:

    "

*生成一份详细的prompt工程指南。**目标受众是<角色>"。（例如，目标受众可能是"书籍作者"、"软件开发者"或"客服代表"）。*

*[xx上下文 - 尽量贴近你的问题]*

*< 3 个我希望prompt如何运作的示例（小样本(few-shot)输入+输出）>*

*< 3 个我希望prompt如何运作的示例（小样本(few-shot)输入+输出）>*

*< 3 个我希望prompt如何运作的示例（小样本(few-shot)输入+输出）>*

*......*

*生成一个可以生成示例输出的prompt，并包含一组更好的示例。*

     "

2. 在新的聊天中，指示它

     "

生成一份详细的prompt评估指南。目标受众是<角色>。

      <上一步生成的prompt>

      评估prompt，并生成 3 个改进的备选prompt

     "

3. 选择最佳的题目，并根据需要进行编辑。

这种方法的一个好处是，LLM 自身的权重会影响提示的生成和评估方式。提示将比您编写的任何内容都要好。最好使用与提示属于同一系列的模型。
