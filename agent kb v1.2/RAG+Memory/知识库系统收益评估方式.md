# 知识库系统收益评估方式

> **Page ID**: 2803411160
> **URL**: https://confluence.shopee.io/pages/viewpage.action?pageId=2803411160

| 评估维度 | 具体指标或评估方式 | 说明 |
| --- | --- | --- |
| 文档覆盖率 | 核心系统/产品线文档接入率（目标 > 80%） | 底座建设完成度的重要体现 |
| 元数据质量 | 元数据字段完备率、自动提取准确率（既定元数据覆盖率>80%） | 支撑过滤检索和图谱构建的关键指标 |
| chunk 策略智能化 | 能否覆盖主流文档类型 + 生成结构合理 | 文档类型分布统计 + 分块质量抽样检查 |
| 知识获取时效 | 平均响应时间下降 80%+ | 从“找人问/人工搜索"转为“秒级获取” |
| 文档利用率 | 访问率 / 引用率提升 | 文档被实际引用次数 vs 总文档数 |
| 文档召回率/准确率 | 各AI应用系统效果反馈，recall和precision提升度 | recall & precision |

| 项目类型 | 可衡量的收益指标 |
| --- | --- |
| 测试用例生成系统 | AI生成用例采纳率提升； |
| 智能告警处理系统 | 告警处理时长缩短（MTTR）；告警分类准确率提升 |
| 研发助手类问答系统 | 平均提问响应时长缩短；重复提问比例下降 |
| Code Review AI助手 | 建议采纳率提升；自动识别错误的能力增强 |
| 接口协作平台 | 联调失败率降低；接口说明文档复用率提高 |

| 评估维度 | 指标示例 | 说明 |
| --- | --- | --- |
| 知识获取时效 | 平均响应时间下降 80%+ | 从“找人问”"人工搜索"转为“秒级获取” |
| 文档利用率 | 访问率 / 引用率提升 3～5 倍 | 文档被实际引用次数 vs 总文档数 |
| 重复劳动减少 | 相似需求答复复用率达 60%+ | 研发/测试/运营在群体提问中的复用情况 |
| 自动处理能力 | AI处理建议采纳率达 70%+ | 在code review、报警分析等场景中的采纳率 |

*数据来源：系统日志、embedding 检索日志、业务部门反馈*
