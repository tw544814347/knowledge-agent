# Milvus数据库

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=3110976644

## 概述

本文档记录 Credit 团队将 HDFS 数据导入 Milvus 向量数据库的技术方案。

## 环境信息

| 项目 | 值 |
| --- | --- |
| Milvus 地址 | http://ytl-credit.data-infra.shopee.io:19530 |
| 可用数据库 | credit / credit_uat / credit_test |
| Embedding 服务 | Compass API https://compass.llm.shopee.io/compass-api/v1 |
| Embedding 模型 | compass-embedding-v4，维度 384 |
| 运行环境 | Jupyter Notebook（集群，/home/jovyan） |

## 更新策略

全量刷新：每次运行时 drop 旧 Collection 并重建。

## 限流处理策略

| 错误类型 | 重试次数 | 等待时间 |
| --- | --- | --- |
| 429 Too Many Requests | 无限重试 | min(10 × retry_count, 60)秒 |
| 其他错误 | 最多10次 | min(2^retry_count, 30)秒 |
