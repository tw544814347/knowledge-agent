# Dify参数配置

> 来源: https://confluence.shopee.io/pages/viewpage.action?pageId=2781057630

本文档汇总 Credit Bot 在 Dify 侧的参数与配置要点。

## 环境变量

Credit Bot 在 Dify 中涉及的主要环境变量包括：

| 变量名 | 说明 |
| --- | --- |
| `error_alarm` | 错误告警相关配置 |
| `SQL_format` | SQL 格式相关配置 |
| `creditmart_common` | Credit Mart 通用配置 |
| `extra_prompt` | 额外提示词 / 补充说明 |
| `bussiness_json` | 业务缩写等业务侧结构化信息（JSON 格式，见文末说明） |

## Prompts

Credit Bot 使用的主要 Prompt 模块包括：

- **Query翻译**
- **用户问题语言重新组织**
- **Biz Info回答生成**
- **表血缘回答生成**
- **业务指标提供**
- **Confluence检索回答生成**

## 知识库 embedding 召回

- **权重设置**：**0.7 : 0.3**（embedding 召回相关权重配置）
- **Top K**：**10**
- **Rerank**：无
- **Score 阈值**：无

## 业务缩写存储说明

所有业务缩写统一存放在环境变量 **`bussiness_json`** 中，以 **JSON** 格式维护，供工作流与 Prompt 读取使用。
