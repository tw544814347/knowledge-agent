# prompts — Prompt 模板管理

统一管理所有发送给 LLM 的 Prompt，遵循模板化原则，禁止硬编码。

## 文件说明

| 文件 | 职责 |
|------|------|
| `templates.py` | System Prompt、QA 模板和上下文构建函数 |

## Prompt 组成

```
┌─────────────────┐
│  System Prompt   │ ← 定义角色、回答规则、输出格式
├─────────────────┤
│  参考文档上下文    │ ← build_context() 从检索结果构建
├─────────────────┤
│  用户问题         │ ← 原始问题文本
└─────────────────┘
```

## 核心组件

- **`SYSTEM_PROMPT`**：角色定义（知识库助手），要求只基于文档回答、标注来源、使用中文
- **`QA_PROMPT_TEMPLATE`**：将上下文 + 问题组装为完整 Prompt
- **`build_context()`**：将检索到的 Top-K chunk 格式化为带来源标注的参考文档
- **`format_qa_prompt()`**：对外调用的入口，一步完成上下文构建 + 模板渲染
